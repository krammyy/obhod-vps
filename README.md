# OBHOD VPS

Клиенты для подключения к своему серверу через sing-box. Выберите версию для вашей платформы.

- [Windows и Linux](desktop/README.md) — настольный клиент на Python. Поддерживает несколько серверов, настройки маршрутизации и импорт параметров подключения.
- [Android](android/README.md) — мобильный клиент на базе sing-box for Android. Поддерживает импорт и редактирование профилей.

## Сборка

Для Windows и Linux следуйте инструкции из папки `desktop/`. Для Android откройте `android/` в Android Studio или используйте Gradle Wrapper. Android-библиотека `libbox.aar` хранится в Git LFS.

В мобильной версии есть примеры профилей. Для подключения укажите параметры своего сервера. Условия лицензии мобильной версии приведены в [android/LICENSE](android/LICENSE).
